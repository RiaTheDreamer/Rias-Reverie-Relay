# Blocking Fidelity

Blocking Fidelity is an opt-in experimental framing mode for Relay Planned and Story Model Planned. It keeps each person's position, appearance, current outfit and action in consecutive owner-specific descriptions. It preserves source-required contact rather than moving people apart to simplify a scene.

Natural Language owner paragraphs are retained when their complete authored wording survives prompt processing. Booru mode keeps singular subject markers and their associated appearance, clothing and spatial tags together. User prompt overrides, provider/model settings, permissions and saved media are preserved.

This mode improves the instructions sent to the model; it cannot guarantee correct anatomy, exact hand placement, contact or actor count. Prefer controlled comparisons with a fixed scene, cast, model, LoRA stack, seed and sampler. Assess each visible dimension independently. See [validation limits](blocking-fidelity-validation.md).
