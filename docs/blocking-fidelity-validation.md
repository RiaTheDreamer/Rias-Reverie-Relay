# Blocking Fidelity validation limits

Automated gates exercise prompt routing, ownership normalization, compiler preservation, both planning workflows and both prompt formats. These checks establish code behavior, not visual accuracy.

Rendered image quality depends on the checkpoint, LoRAs and generation settings. Completed slots are not evidence that posture, contact, clothing or anatomy match the story. Small local comparisons have not established a reliable anatomy or exact-contact guarantee.

For meaningful comparisons, preserve the original images and actual outgoing generation settings. Score actor count, posture, exact hands/contact, prop ownership, clothing, framing and anatomy separately. Prism Lab supports this comparison workflow without generating images. See [illustration controls](illustration-weave.md).
